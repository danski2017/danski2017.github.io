# C009 Clean GFRO Jurisdiction Benchmark

## Purpose

C009 builds a clean source/context jurisdiction benchmark outside the EMS rehearsal ledger.

The question:

```text
When source/context parity is extracted from controlled scenes,
do tensor-Frobenius electric-Weyl witnesses and scalar acceleration
witnesses produce the same jurisdiction radii?
```

## Scene Family

One declared unit source at the origin.

Five context scenes:

- single equal-mass context datum at `x = 10`,
- single 10x-mass context datum at `x = 10`,
- balanced off-axis binary context,
- tilted 12-datum ring context,
- deterministic 48-datum many-source cloud context.

Each scene was sampled over 192 exterior directions. Along each ray, C009 extracted the first source/context parity crossing for:

- tensor-Frobenius electric-Weyl/tidal branch,
- scalar acceleration branch.
