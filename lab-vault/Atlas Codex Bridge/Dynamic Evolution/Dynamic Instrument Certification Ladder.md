# Dynamic Instrument Certification Ladder

This ladder prevents the dynamic animation from being over-promoted.

## Status Vocabulary

Scaffold:
architecture or code path exists, but no successful run yet.

Observed:
successful result in one scene or session.

Reproduced:
independent rerun or second scene confirms the result.

Stress-Tested:
result survives resolution, parameter, scene, and tolerance sweeps.

Certified:
result has ledger-grade outputs, reproducibility, constraints, comparison branch, failure-mode audit, and clear claim ceiling.

## Certification Requirements

R5 promotion requires:

- second independent scene
- `c_toy` sweep confirming `1/c^2` scaling
- ray-count sweep
- radial-resolution sweep
- source-count or mass-ratio variation
- ledgered self/context/cross decomposition
- comparison against R2 linearized extraction
- declared GFRO residual mode
- current self-contaminated R5 retained only as anomaly lane
- self-cleaned and cross-retaining candidates compared before certification

`K_ij` promotion requires:

- reproduction in a second scene
- momentum constraint monitor
- Hamiltonian residual convergence study
- gauge declaration
- comparison against an ADM branch or controlled weak-field expectation

Seam/node promotion requires:

- proximity threshold sweep
- point-cloud density sweep
- persistence tracking across steps
- false-positive check in separated scenes
- lineage identity across time
- source-fixed normalized threshold rerun
- GFRO retained-boundary relevance filter

Atlas-native engine promotion requires:

- declared field-derived update rule
- no hidden Newtonian leapfrog as the primary driver
- conservation audit
- constraint audit
- comparison against Newtonian and ADM-like branches
- clear failure cases

## Forbidden Promotion Moves

- Do not call ADM wrong before Atlas passes its own constraints.
