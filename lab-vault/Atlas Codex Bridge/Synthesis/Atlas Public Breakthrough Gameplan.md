# Atlas Public Breakthrough Gameplan

This is the execution plan for turning the current lab stack into visible, repeatable, public-facing science.

## North Star

Atlas becomes the lab that maps finite-source gravitational identity and source/context curvature structure inside GR-governed scenes.

Public sentence:

```text
Finite matter has gravitational identity.
Context decides where it matters.
Compression decides when detail fades.
GFRO maps the relation.
Lumen makes the relation visible.
Simulations test what standard averaging loses.
```

## Operating Split

```text
repo + codex_context -> experiments, code, summaries
Obsidian bridge -> durable lab memory, doctrine, claim gates
website -> public solver, papers, interactive explainers
```

The website is the public edge. Obsidian is the memory. The repo is the machine shop.
