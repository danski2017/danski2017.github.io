## 1. Purpose

Record that C5 has split into two lawful branches after dimensional preflight and the Bel-Robinson comparison gate.

The split prevents the finite-domain electric-Weyl ledger from being treated as radiative flux, ordinary energy, or conservation evidence. It also preserves a separate Bel-Robinson/radiative comparison branch for later theory maturation.

Object:

```text
finite-domain electric-Weyl square ledger
```

Candidate form:

```text
B_E(a) = integral_domain E_ij E^ij dV
```

Role:

- near-zone diagnostic ledger,
- electric-Weyl finite-domain bookkeeping,
- separation-dependent diagnostic candidate,
- possible analytic scratch branch if later authorized.

Not role:

- not radiative flux,
- not ordinary energy,
- not conservation claim,
- not gravitational-wave luminosity,
- not experiment evidence.

Required declarations:

- source radius or exclusion/worldtube rule,
- equal-mass circular binary geometry,
- weak-field approximation,
- whether cross-terms are included,
- whether self-budget and interaction-budget are separated.

curvature-square/superenergy comparison family

## 4. First Calculation Recommendation

Recommendation:

```text
C5-A first as analytic diagnostic branch, provided it stays explicitly non-radiative.
```

Reason:

C5-A has the narrower object and can be framed as dimensional and finite-domain bookkeeping without claiming a wave-zone flux. It can test whether self terms, interaction/cross terms, cutoff dependence, and separation dependence are even well-defined. C5-B remains a theory/literature comparison gate until the Bel-Robinson/superenergy object choice, observer/tetrad convention, and radiative extraction target are mature.

Repo execution remains unauthorized. The next step should be a no-code calculation passport, not a calculation.
