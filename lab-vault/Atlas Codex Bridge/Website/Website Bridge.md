## Bridge Rule

Do not use the website as the source of truth.

Use:

```text
Obsidian note -> claim-safe public copy -> website page/update
```

For each public update, the vault should already contain:

- paper or result note,
- claim status,
- non-claims,
- public-facing title,
- public-facing abstract or short description,
- source artifact path,
- next-gate status.

## Website Publication Ladder

1. Internal run or paper artifact exists.
2. Obsidian note records doctrine, evidence, claim ceiling, and non-claims.
3. Public copy is drafted from the Obsidian note.
4. Website page or news entry is updated.
5. Links are checked.
6. Site is previewed locally or through GitHub Pages.
7. Public claim is reviewed against `Claim Boundaries`.
