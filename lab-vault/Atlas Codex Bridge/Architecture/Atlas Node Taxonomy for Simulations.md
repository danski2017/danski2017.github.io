# Atlas Node Taxonomy for Simulations

This note adapts the Atlas node bootloader into simulation practice.

## Primary Nodes

### Node -1

Certified relational ledger.

Simulation role:

- stores what the run lawfully remembers,
- preserves source/datum role separation,
- records retained/coarse branch summaries,
- records GFRO-emitted diagnostic candidates and summary registries,
- supports interpretation but is not interpretation itself.

### Node 0

Primary geometric registration datum.

Simulation role:

- coordinate/registering reference,
- origin or reporting datum when declared,
- never a physical source merely because it is central.

### Node 1

Mandatory lawful parent scene relation.

Simulation role:

- null exterior,
- explicit parent scene,
- inherited parent relation,
- observational/asymptotic boundary,
- parent/context condition.

Forbidden:

- calling Node 1 a scalar floor,
- treating Node 1 as a hidden source unless explicitly declared active.

### Node 2+

Physical source nodes.

Simulation role:

- source proxies,
- stars,
- clusters,
- field particles,
- parent sources if explicitly active,
- stress-energy/source contributors in the declared approximation.

Only Node 2+ physical sources generate modeled field contribution unless a parent source is explicitly declared active.

## Derived / Diagnostic Nodes

### Node G

Geometric centroid of declared source positions.

Computed diagnostic. Not automatically Node 0.

### Node B

Mass barycenter of declared sources.

Computed diagnostic. Not sovereign center.

### Node Psi

Extracted GCS/parity-context diagnostic layer.

Derived from GFRO source/context relation maps and field-sieve emission into ledgered diagnostic registries. Not a force, source, membrane, or evidence by itself.

### Node P

Parity-junction candidate.

Not automatically critical.

### Node A

Earned adjudication / critical-transition candidate.

Requires validation. Never automatic.

Each serious run should include:

```text

```

## GFRO Emitter Language

Preferred:

- GFRO maps declared source/context residuals.
- The field-sieve emits coordinate candidates.
- Node -1 records the emitted ledger.
- Witnesses rank candidates.
- Retention certifies scaffolds.

Avoid as default architecture language:

- "queries extract" as the main engine description,
- "surfaces are found by render inspection",
- "Node Psi decides."
