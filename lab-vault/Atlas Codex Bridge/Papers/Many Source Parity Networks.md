# Many Source Parity Networks

## Status

Public GCS series paper. April 2026.

## Digest

Extends GCS from contribution-context parity to many-source parity. Each source receives a declared source-readable contribution `Q_i`; pairwise equality `Q_i = Q_j` defines a parity surface. In the weak-field scalar tidal branch `Q_i ∝ M_i / r_i^3`, equal masses recover the midpoint plane and unequal masses obey `r_i / r_j = (M_i / M_j)^(1/3)`. For three or more sources, retained portions of pairwise parity surfaces assemble into a many-source parity network.

## Current Relevance

Important lineage for many-source parity and relational network intuition.

## Current Use

Useful for explaining why Atlas treats relational source structure as primary. Current work should still distinguish parity readability from GR-governed field interpretation.

## Claim Boundary

The network is a derived diagnostic geometry, not a force boundary, physical barrier, causal horizon, orbital-stability limit, or new invariant. It does not report numerical extraction results; it supplies the public mathematical scaffold for later extraction and interpretation.
