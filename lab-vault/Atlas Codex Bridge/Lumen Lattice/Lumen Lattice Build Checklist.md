# Lumen Lattice Build Checklist

Use this checklist when building or reviewing any Lumen Lattice, released-coordinate lattice, wireframe viewer, or truss/rib scaffold render.

## Required Declarations

- Scene ID.
- Claim status.
- Node -1 ledger policy.
- Node 0 registration datum.
- Node 1 parent/context relation.
- Node 2+ physical source roster.
- Datum roster.
- Witness roster.
- GFRO relation-map declaration.
- Field-sieve emission rule.
- Lumen release rule.
- Render lane and non-claim language.

## Source / Datum Split

Pass only if:

- sources contribute field terms,
- datums interrogate or display,
- the lattice is declared as a datum witness,
- render camera/grid objects are not treated as sources,
- parent context is visible in metadata even when visually muted.

## GFRO Before Lumen

For serious lanes, generate or declare:

- source/context relation map,
- emitted zero-set registry,
- faces/seams/junctions where applicable,
- low-margin regions,
- parent/context support envelopes,
- wireframe scaffold candidates,
- Node P or Node A candidate status when used.

The Lumen Lattice should be released after this architecture is ledgered or explicitly marked as a sandbox visual scout.

## Tensor / Eigen / Weyl Witnesses

Where curvature-side meaning is being tested, include:

- tidal tensor or Hessian proxy,
- electric-Weyl tensor where lawful,
- eigenvalues,
- eigenframes,
- Ricci/Weyl or custody/inheritance diagnostic where available,
- scalar invariants only as supporting witnesses.

## Lumen Release Rule

Record:

- lattice domain,
- lattice resolution,
- edge construction rule,
- displacement direction rule,
- displacement magnitude normalization,
- release gain,
- clipping or scaling,
- whether source motion is live or static,
- whether the lattice is recomputed or merely rotated.

## Viewer Requirements

Minimum:

- source markers,
- Node 0 marker when meaningful,
- Node 1/parent context metadata,
- Lumen lattice toggle,
- GFRO overlay toggle,
- opacity controls,
- claim ceiling visible,
- provenance visible.

Preferred:

- source labels,
- GFRO family legend,
- density or edge-stride control,
- local/global view presets,
- screenshot/export receipt,
- smoke-test summary.

## Claim Boundary Text

Include some version of:

```text
The Lumen Lattice is a released datum witness and diagnostic visualization. It is not material spacetime, not proof by render, and not an extraction authority.
```

## Failure Modes

Stop or downgrade if:

- the lattice is tuned visually without recording the rule,
- parent context disappears from the declaration,
- GFRO overlays are decorative rather than ledgered,
- the render is used as evidence,
- visual beauty replaces matched baselines or resolution checks,
- lattice nodes are described as physical particles,
- wireframe candidates are promoted without retention.

## Closeout Artifacts

Every serious build should leave:

- scene passport,
- payload summary,
- viewer receipt,
- claim-status note,
- artifact manifest,
- data-size report,
- next-gate list,
- Obsidian note update.
