# Atlas Platform Archive

This archive holds immutable receipts for material Atlas Platform milestones.
It is not a duplicate of the large viewer datasets or analysis tree.

## Rules

- One dated receipt per material platform change or release baseline.
- Never edit a historical receipt after it is superseded; add a correction or a
  newer receipt.
- Record source hashes, affected lanes, schema changes, validation, screenshots,
  claim-boundary impact, and rollback/removal instructions.
- Large binaries remain in the repo analysis tree and are referenced by path and
  manifest hash rather than copied into Obsidian.
- Numerical run detail belongs in the repo append-only lab log and run manifest.
