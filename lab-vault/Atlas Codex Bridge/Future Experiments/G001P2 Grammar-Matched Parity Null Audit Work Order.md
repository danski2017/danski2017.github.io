- Hill-style boundary proxy is a contextual comparator.
- It is not a grammar-matched null.
- It should not be used to claim that Hill boundaries physically outperform parity surfaces.

Valid G001P read:

- first-pass parity proxy did not dominate the tested comparators,
- no public parity-validation claim is earned.

- parity is falsified by the Hill-style proxy.
