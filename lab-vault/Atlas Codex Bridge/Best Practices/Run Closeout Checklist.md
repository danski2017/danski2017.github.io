# Run Closeout Checklist

## Before Calling A Run Complete

- Config written.
- Scene passport written.
- Derived table written.
- Report written.
- Interpretation note written.
- Run summary written.
- Manifest written with file hashes.
- Package size checked.
- Claim boundary explicit.
- Non-claims explicit.
- Obsidian experiment note updated.
- Live Experiment Dashboard updated.
- Next Simulation Queue updated if needed.

## If The Run Is Large

- Record package size.
- Prefer summary-only follow-up if raw ledgers are not necessary.
- If deleting stale payloads, preserve deletion manifest.

## If The Run Fails

- Preserve failure mode in notes.
- Do not soften negative result.
- Ask whether the failure is numerical, architectural, or conceptual.
- If useful, promote failure into a null/failure-mode note.
