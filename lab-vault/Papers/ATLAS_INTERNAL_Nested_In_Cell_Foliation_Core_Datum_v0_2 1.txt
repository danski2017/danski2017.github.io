================================================================================
ABSTRACT
================================================================================

This internal note synchronizes the nested in-cell foliation hypothesis with the current Atlas vocabulary and claim discipline. The working hypothesis is that a certified GCS or retained parity-context cell is not exhausted by its outer parity boundary. Within a declared weak-field readability rule, the boundary may be treated as the zero-level leaf of an inward threshold family generated by a readable-margin field. The resulting nested in-cells contract toward a limiting core datum or core set, providing a possible surface-to-volume continuation grammar for internal Atlas diagnostics.

The hypothesis remains internal. It does not modify general relativity, introduce a new force, define a new invariant, claim full metric reconstruction from boundary data, or promote child datums to canonical physical sources. It proposes a derived diagnostic calculus: boundary first, margin field second, threshold ladder third, datum trajectory fourth, recursive refinement only after validation.

4. FORMAL SETUP
================================================================================

Let a declared weak-field scene be evaluated on a chosen spatial slice Sigma_t. Let source S_i have mass M_i, position x_i, and softened distance

    r_{i,eps}(x) = sqrt(||x - x_i||^2 + eps^2).

The current Phase I scalar readable branch is

    Q_i(x) = M_i / (||x - x_i||^2 + eps^2)^(3/2).

Away from sources and in analytic shorthand,

    Q_i(x) proportional to M_i / r_i(x)^3.

Define the source-readable margin of source i against its strongest local competitor by

    m_i(x) = Q_i(x) - max_{j != i} Q_j(x).

Then the retained readable cell, strict interior, and outer parity boundary are

    C_i      = { x in Sigma_t : m_i(x) >= 0 },
    C_i^+    = { x in Sigma_t : m_i(x) > 0 },
    dC_i     = { x in Sigma_t : m_i(x) = 0 }.

For threshold tau >= 0, define the nested in-cell family

    C_i(tau) = { x in Sigma_t : m_i(x) >= tau }.

If tau_2 > tau_1 >= 0, then

    C_i(tau_2) subset C_i(tau_1) subset C_i(0) = C_i.

Let

    tau_i* = sup_{x in Sigma_t} m_i(x),

and define the limiting core set

    K_i = { x in Sigma_t : m_i(x) = tau_i* }.

If K_i is pointlike, it may be called the core datum. If K_i is extended, it is a core datum set. The extended case is not a defect. It may indicate anisotropy, elongation, degeneracy, symmetry, or insufficient resolution.

================================================================================

Under this hypothesis, a parity boundary is not merely the place where readable handoff occurs. It is the outermost certified leaf of an interior readable foliation. The cell becomes a thresholded readable volume, and the core datum or core set becomes the limiting object of that threshold family.

Internal hierarchy:

- parity face: readable handoff surface;
- retained cell: readable dominance volume;
- in-cell ladder: nested readable interior;
- core datum or core set: limiting inner diagnostic object;
- datum trajectory: path of interior centers across the threshold family.

No coarse averaging is required. The nested cells are produced by thresholding the declared margin field. Atlas is not smearing the field. It is interrogating the declared readable interior.

6. FIRST DIAGNOSTIC QUANTITIES
================================================================================

Once C_i(tau) is defined, the first diagnostic quantities are:

    V_i(tau) = integral_{C_i(tau)} dV,

    A_i(tau) = integral_{dC_i(tau)} dA,

    c_i(tau) = (1 / V_i(tau)) integral_{C_i(tau)} x dV.

V_i(tau) is the in-cell volume. A_i(tau) is the in-cell boundary area. c_i(tau) is the in-cell geometric center.

The path c_i(tau) is the datum trajectory of the cell. In a symmetric cell it should remain fixed. In a mildly deformed cell it should drift smoothly. In a strongly anisotropic cell it may bend or split. The cell therefore gains an internal diagnostic geometry, not merely an outer boundary.

Additional candidate diagnostics:

- shrink law: V_i(tau) / V_i(0);
- area law: A_i(tau) / A_i(0);
- compactness proxy: A_i(tau)^3 / V_i(tau)^2, with units and normalization declared;
- centroid drift length: ||c_i(tau) - c_i(0)||;
- core multiplicity: number of connected components of K_i;
- component count of C_i(tau);
- closure persistence across tau;
- sensitivity of K_i and c_i(tau) to sampling, domain, and tolerance.

These are diagnostics, not observables by themselves.

7. SURFACE-TO-VOLUME CONTINUATION
================================================================================

Within a declared readable regime and under sufficient local smoothness, the certified parity boundary together with local derivative data of the readable margin may constrain a lawful continuation into the interior readable organization of the cell.

This should not be framed as black-hole holography or universal boundary determination. The safer language is surface-to-volume continuation or boundary-registered interior foliation.

Two complementary internal towers may be useful:

Offset tower:

    dC_i(tau) = { x : m_i(x) = tau }.

Derivative tower, evaluated on dC_i or selected in-cell leaves:

    partial_n m_i,
    partial_n^2 m_i,
    partial_n^3 m_i,
    ...

The offset tower generates nested leaves. The derivative tower measures transition stiffness, curvature, and local margin behavior across those leaves. Together they may form a first local grammar for interior-cell diagnostics.

8. HYPOTHESES
================================================================================

H1. Nested in-cell existence.
If the readable fields are continuous and the retained cell C_i is compact on the chosen slice, then C_i(tau) exists for 0 <= tau <= tau_i* and forms a nested family.

H2. Core convergence.
As tau approaches tau_i*, the nested in-cell family contracts to a nonempty compact core set K_i, provided the supremum is attained on the compact cell.

H3. Core shape significance.
A pointlike K_i may function as a core datum. An extended or multi-component K_i may encode anisotropy, symmetry, degeneracy, or unresolved interior structure and must not be collapsed to a point without justification.

H4. Datum trajectory regularity.
Where C_i(tau) varies smoothly with tau and remains connected, c_i(tau) defines a lawful interior datum trajectory whose behavior may encode deformation of the readable cell.

H5. Boundary-registered continuation.
Within a declared readable regime and under sufficient smoothness, the outer parity boundary plus local margin derivative data constrains, but does not uniquely determine in all cases, the interior threshold foliation.

H6. Child-datum candidate rule.
A certified in-cell leaf or core datum may provide a principled candidate support for child-datum generation. It does not automatically become canonical; it must beat simpler baselines and pass validation.

================================================================================
11. TEST PROGRAM
================================================================================

Stage 1: symmetric anchor.
Use an isolated or near-isolated symmetric scene. The core datum should be fixed and pointlike or symmetry-consistent. False drift is a numerical warning.

Stage 2: equal-mass two-source cell.
Check that in-cell behavior respects the midpoint parity structure and does not invent spurious child datums.

Stage 3: unequal-mass deformation.
Mass-sensitive deformation should produce smooth, interpretable shifts in C_i(tau), c_i(tau), and K_i.

Stage 4: equal-mass three-source benchmark.
Track whether central junction structure interacts with in-cell contraction without creating false Node A or false child/parent claims.

Stage 5: perturbed/lopsided cells.
Test whether datum trajectories bend smoothly and whether K_i becomes extended or multi-component in a reproducible way.

Stage 6: baseline challenge.
The nested in-cell method must do at least one of the following better than the simpler omni-radial baseline: recover genuinely new structure, recover the same structure with materially better fidelity, or support lineage-aware recursive refinement more cleanly.

Stage 7: artifact rejection.
Repeat across sampling, tolerance, domain size, threshold schedule, and render style. A nested feature that fails modest changes is scratch-only.
