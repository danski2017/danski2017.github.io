ABSTRACT
================================================================================

This synchronized note preserves the viable core of the earlier hypothesis block:
once a weak-field scene and readable comparison rule are declared, a formal parity
zero-set scaffold is immediately implied by the comparison fields. This structure is
not created by rendering, calibration, or later recursive refinement. It follows
from the declared source-readable contributions Q_i and their residuals

    Psi_ij(x) = Q_i(x) - Q_j(x).

The formal zero sets

    Sigma_ij = { x : Psi_ij(x) = 0 }

exist mathematically as soon as Q_i and Q_j are declared.

However, current Atlas doctrine requires a strict distinction between formal
existence and evidentiary use. The raw zero-set scaffold exists as a mathematical
object of the declared field. The retained parity network is an extracted diagnostic
object. A datum scaffold is not automatically granted. Retention, ledger
certification, relevance filtering, topology checks, and sensitivity validation are
required before any portion of the formal scaffold may support Node Psi geometry,
Node P junction candidates, Node A criticality candidates, or recursive
datum-candidate logic.

The useful internal triad is:

    faces divide;
    seams connect;
    junctions nominate;
    criticality resolves only if earned.

This note therefore demotes “immediate datum scaffold” to “scene-implied diagnostic
scaffold candidate.” The idea remains valuable, but it must not outrank Node 0,
Node 1, Node -1, or canonical Phase I extraction.

5. FORMAL SETUP
================================================================================

Let a declared weak-field scene contain physical sources S_i with masses M_i and
positions x_i on a chosen static or quasi-static slice.

Define the Phase I scalar readable branch

    Q_i(x) = M_i / (||x - x_i||^2 + eps^2)^(3/2),

or, away from sources,

    Q_i(x) proportional to M_i / r_i(x)^3.

For every pair i, j, define the comparison residual

    Psi_ij(x) = Q_i(x) - Q_j(x).

The formal parity surface is

    Sigma_ij = { x : Psi_ij(x) = 0 }.

The formal all-pairs zero-set scaffold is

    S_formal = union over i<j of Sigma_ij.

This object is mathematically implied by the declared scene and readable rule.

The retained parity network is narrower:

    N_retained = union over (i,j) in R of I_ij,

where

    I_ij subset Sigma_ij

is the retained portion of the formal parity surface and R is the declared
retention relation.

The key distinction:

    S_formal is implied.
    N_retained is extracted.
    Scaffold interpretation is earned.

================================================================================

The hypothesis block’s strongest internal grammar is codimensional:

    One independent equality:
        Q_i = Q_j.

Role:

Codimension 2:

constrained scenes.

    Three independent equality or criticality-related constraints, where stable.

Role:

automatic.

Synchronized triad:

    faces divide;
    seams connect;
    junctions nominate;
    criticality resolves only if earned.

This grammar is internal and diagnostic. It does not imply discrete spacetime,
quantized gravity, physical nodes, or automatic observational status.

7. RELATION TO NODE PSI, NODE P, AND NODE A
================================================================================

Node Psi:
The extracted GCS/parity-context diagnostic layer. Retained parity faces, seams,
junction candidates, and cells belong here after extraction and filtering.

Node P:
A parity-junction candidate. A Node P candidate may occur where retained parity
surfaces meet or nearly meet in a stable way.

Node A:
An adjudication / critical-transition candidate. Node A is not a generic parity
junction. It is earned only when diagnostics suggest a real transition in closure,
topology, contextual assignment, or GCS coherence under deformation.

Rule:
Every Node A candidate may pass through Node P-like junction evidence, but not
every Node P candidate is Node A.

The source hypothesis over-compressed this distinction by treating adjudication
nodes as generic resolution anchors. Synchronized doctrine requires a ladder:

    formal zero set
    -> retained parity face
    -> seam / junction candidate
    -> Node P candidate
    -> Node A candidate only if criticality diagnostics pass.

adding testable discipline.

meaning.

not an active branch.
