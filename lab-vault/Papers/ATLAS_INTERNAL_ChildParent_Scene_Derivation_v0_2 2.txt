================================================================================
ABSTRACT
================================================================================

This synchronized internal note preserves the viable core of the earlier child/parent
scene-derivation white paper while repairing its terminology against current Atlas
canon.

The core insight is that the old scalar “floor” problem in local scene analysis is
better understood as a missing parent-context problem. A child scene should not be
judged against an arbitrary scalar threshold when the relevant question is instead:
what lawful parent relation contextualizes this scene under the declared weak-field
readability rule?

In current Atlas doctrine, Node 1 is not a scalar floor and not a physical source.
Node 1 is the mandatory lawful parent scene relation for a declared scene. A derived
parent support may be extracted as a contextual diagnostic object under a declared
branch, but it does not replace the underlying GR field, does not generate curvature,
and does not become a new physical source.

The motivating case remains the Earth-Moon-Sun scene. Earlier child-side analysis
approached legibility but stalled because the final comparison datum remained
under-derived. The child/parent branch proposes to replace arbitrary threshold
selection with a lawful outward context search: define the child scene, declare a
candidate parent scene, compare parent-readable contribution against outside
context, and test whether the resulting parent support is stable, enclosing, and
reproducible.

The earlier strict EMS audit remains a high-value internal result seed. With child
C = {Earth, Moon}, parent candidate G = {Earth, Moon, Sun}, and an outer local
stellar context, an independent replication recovered a median fractional
proxy-versus-strict shell separation of order 10^-6, specifically about
9.29 x 10^-7, with uniformly positive sign over 326/326 closed directions. That
sign is physically sensible: adding the child masses to the parent channel
strengthens the parent-readable contribution and pushes the closure crossing
outward. The result is Sun-dominated but not Sun-trivial.

This memo does not certify Node 1 derivation as solved. It does not establish a
canonical child/parent extraction standard. It records a promising internal branch
and defines the vocabulary, equations, output requirements, and validation gates
needed to harden it.

6. DECLARED READABLE BRANCH
================================================================================

Let a declared weak-field scene contain physical sources S_i with masses M_i and
positions x_i on a static or quasi-static slice.

Define softened distance

    r_{i,eps}(x) = sqrt(||x - x_i||^2 + eps^2).

The current Phase I scalar readable branch is

    Q_i(x) = M_i / (||x - x_i||^2 + eps^2)^(3/2).

Away from sources, analytic shorthand may be written

    Q_i(x) proportional to M_i / r_i(x)^3.

This Q_i is a diagnostic readable field inspired by tidal scaling. It is not the
metric, not a force, and not an observable by itself.

For pairwise comparison,

    Psi_ij(x) = Q_i(x) - Q_j(x).

For a declared child/parent comparison, let C be the child scene and G be a
candidate parent group with C subset G. The parent-readable channel may be
defined as

    Q_G(x) = sum_{i in G} Q_i(x).

The outside competitor or outside context channel must be declared. A simple
branch may use

    Q_out(x; G) = max_{j not in G} Q_j(x),

while richer branches may use a summed, tensor-aware, sector-resolved, or
parent-ledger context. The branch must declare which is being used.

Define the parent residual

    Psi_G(x) = Q_G(x) - Q_out(x; G).

A candidate parent support is the zero set

    Sigma_G = { x : Psi_G(x) = 0 },

retained only where closure, sampling, and validation rules support
interpretation.

7. CHILD/PARENT DERIVATION PIPELINE
================================================================================

The synchronized branch pipeline is:

1. Declare the child scene C.
   Specify child sources, units, coordinates, approximation regime, and physical
   source roster.

2. Declare the child witness datum.
   Default candidate: mass barycenter x_B(C). Alternatives must be named and
   justified.

3. Declare Node 0 registration.
   The scene’s global coordinate registration datum must be explicit.

4. Declare Node 1 parent relation.
   The scene is not parentless. State whether the parent relation is explicit,
   inherited, canonical external, or observational/asymptotic.

5. Propose candidate parent group G.
   Require C subset G. Example: C = {Earth, Moon}; G = {Earth, Moon, Sun}.

6. Declare outside context K(G).
   Specify whether outside context is max-source, summed-source, sector-resolved,
   local stellar neighborhood, ephemeris roster, null exterior, or another branch.

7. Compute Q_i and ledger the relational state.
   Store Q_i, Q_G, Q_out, Psi_G, source roster, parent roster, outside roster,
   sampling metadata, and anchor convention.

8. Launch omni-radial interrogation.
   Default serious branch: launch rays from the declared child witness datum or
   explicitly declared anchor. Anchor must be fixed for proxy-versus-strict
   comparisons.

9. Extract first closure crossings.
   Along each ray, solve for Psi_G = 0 where a crossing exists.

10. Score parent support.
    Record closed-ray fraction, median closure radius, radius dispersion,
    anisotropy, sign consistency, component behavior, and persistence under
    context growth.

11. Compare proxy and strict branches if applicable.
    Hold anchor convention fixed. Do not compare ppm-level shell separation
    across different launch anchors.

12. Validate.
    Run sampling, radial, tolerance, domain, source-roster, and anchor checks.

13. Interpret conservatively.
    Treat the parent support as a derived contextual diagnostic unless stronger
    evidence is earned.

================================================================================
9. STRICT AUDIT RESULT SEED
================================================================================

The source paper records an independent Claude-wing replication of the EMS strict
audit. The reported result:

    median fractional proxy-versus-strict separation approximately 9.29 x 10^-7;
    326/326 closed directions positive;
    strict shell uniformly larger than proxy shell.

Interpretation:
Adding Earth and Moon into the parent channel strengthens the parent-readable
contribution relative to the proxy and pushes the closure crossing outward. The
positive sign is physically and methodologically expected.

Current evidence status:
High-value internal result seed. Not canonical evidence yet.

Required caution:
The fractional correction is at ppm scale. Launch-anchor choice can introduce
changes of comparable order when parsec-scale shells are read from anchors
separated by astronomical-unit scales. Therefore any proxy-versus-strict
comparison must fix and hold the anchor convention.

The audit supports three provisional lessons:

1. Gross parent-shell existence and morphology are not very sensitive to anchor
   choice at this scale.

2. The ppm-level child correction is sensitive to anchor convention and must not
   be compared across mixed anchors.

3. The parent support is overwhelmingly Sun-led while retaining a lawful
   Earth-Moon fingerprint under the declared branch.

================================================================================
10. ANCHOR CONVENTION LAW
================================================================================

Anchor discipline is mandatory for this branch.

For gross morphology:
Anchor choice may be negligible when the shell scale is parsecs and anchor shifts
are AU-scale.

For ppm correction:
Anchor choice is not negligible. A shell separation of order 10^-6 can be
contaminated or mimicked by changing launch anchors.

Therefore future strict audits must declare:

- launch anchor;
- child witness datum;
- whether proxy and strict runs use identical anchors;
- coordinate frame;
- radial parameterization;
- ray set;
- radial search bounds;
- interpolation method;
- closure criterion;
- comparison statistic.

Rule:
Do not report proxy-versus-strict fractional separation unless the proxy and
strict extractions share the same launch-anchor convention.

16. WHY THIS MATTERS FOR MANY-SOURCE SCENES
================================================================================

The branch suggests a scalable hierarchy strategy:

    child scene
    -> first lawful parent relation
    -> larger parent relation
    -> context ring
    -> broader scene

This avoids two bad extremes:

1. flat all-pairs fog, where every comparison competes for equal interpretive
   rank;

2. immediate global averaging, where local scene structure is erased too early.

Instead, the child/parent branch asks whether meaningful intermediate supports
can be derived and validated.

For the 12-source scene family, this means local sub-scenes may be tested for
lawful parent supports before being interpreted inside the global cluster.

For galaxy-scale work, this suggests a cautious future ladder:
local subsystem, stellar neighborhood, association, arm/cluster context, galaxy
context, group context.

This is a research strategy, not a proven scaling law.

19. FAILURE MODES
================================================================================

F1. Parent support disappears or changes qualitatively under modest sampling,
domain, or tolerance changes.

F2. Proxy-versus-strict separation vanishes or changes sign under controlled
rerun.

F3. Claimed child correction is dominated by anchor convention.

F4. Outer context roster changes swamp the parent support without predictable
behavior.

F5. The branch adds complexity but does not improve scene lawfulness or
diagnostic interpretation.

F6. Parent supports are interpreted as physical shells, force walls, or new
sources.

F7. Renders look coherent but ledgered diagnostics fail to support the claimed
structure.

F8. The branch distracts from canonical Phase I stabilization.

If these failure modes dominate, the branch should remain historical or
scratch-only.
